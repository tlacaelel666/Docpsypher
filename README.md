</div><!-- SECCIÓN 1: INTRODUCCIÓN Y VISIÓN --><div style="border: 1px solid #e0e0e0; padding: 20px; border-radius: 8px; margin-bottom: 30px; background-color: #f9f9f9;"><h2 style="color: #4A90E2; border-bottom: 2px solid #4A90E2; padding-bottom: 10px;">✨ La Visión: Seguridad basada en Principios Cuánticos</h2><p>Docpsypher busca modelar un sistema de seguridad digital utilizando conceptos de la <strong>Polaridad Gravitacional Cuántica</strong>. El objetivo es crear firmas de datos que posean las propiedades de unicidad e irreplicabilidad que caracterizan a los fenómenos físicos a nivel cuántico.</p></div><!-- SECCIÓN 2: MECANISMOS FUNDAMENTALES (La Teoría) --><div style="margin-bottom: 30px;"><h2 style="color: #E24A90;">🔬 Mecanismos Fundamentales del Protocolo</h2><p>El protocolo se fundamenta en tres conceptos primordiales, que se traducen en un sistema de cifrado y firma:</p><div style="display: flex; gap: 20px; flex-wrap: wrap;">

    <!-- Tarjeta 1: Polaridad -->
    <div style="flex: 1; min-width: 250px; padding: 15px; border: 1px solid #E24A90; border-left: 5px solid #E24A90; border-radius: 5px;">
        <h3 style="margin-top: 0; color: #E24A90;">1. Polaridad (Mecánica 1/0)</h3>
        <p>La **Polaridad** se define como la mecánica de un sistema elemental que opera en dos estados binarios: <strong>1 (Presencia)</strong> o <strong>0 (Ausencia)</strong>. Es la forma en que los fenómenos cuánticos se mapean a la lógica computacional.</p>
    </div>

    <!-- Tarjeta 2: Repulsión Persistente -->
    <div style="flex: 1; min-width: 250px; padding: 15px; border: 1px solid #E24A90; border-left: 5px solid #E24A90; border-radius: 5px;">
        <h3 style="margin-top: 0; color: #E24A90;">2. Repulsión Persistente</h3>
        <p>Este concepto se interpreta como un <strong>movimiento oscilatorio</strong> a una velocidad inimaginable. Esta oscilación subyacente genera las excitaciones y vibraciones (las "cuerdas") que son capturadas por el protocolo para codificar los datos.</p>
    </div>

    <!-- Tarjeta 3: Firma Radiactiva -->
    <div style="flex: 1; min-width: 250px; padding: 15px; border: 1px solid #E24A90; border-left: 5px solid #E24A90; border-radius: 5px;">
        <h3 style="margin-top: 0; color: #E24A90;">3. Firma Radiactiva</h3>
        <p>La firma se construye combinando los estados de Polaridad, los valores de **Fase Cuántica** (en radianes) y las métricas de **Decaimiento** (energía y vida media) extraídas de modelos de elementos radiactivos.</p>
    </div>
